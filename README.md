## TrabajoFinal-Grupo104
Presentación del Trabajo Final Integrador de la Tecnicatura de Programación

Tecnologias a utilizar.
Backend: Java + Spring Boot
Frontend: TypeScript + React
Base de Datos: MongoDB Atlas
Plataforma de despliegue: Vercel (Fronted) - Render (Backend)
Projecto con Graddle

# Etapa 1:
- Obtener información actualizada de modelos de vehículos automotores.
- Tomar datos de usuarios y guardarlos
- Calcular valor del seguro según múltiples factores (como: región, edad, tipo de combustible, etc)
- Generar estadística de los presupuestos generados (refleja cuantos clientes continuaron después de la consulta inicial, y de que zona pertenece, etc)
